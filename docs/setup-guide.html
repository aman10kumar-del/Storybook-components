Project setup

If you got a .zip, it leaves out node_modules and git history so the file stays small — unzip, then follow these steps in order.

Unzip the project

Double-click the zip (or use your OS extract tool). You should get one folder named PODS AI WGMI — keep that name or rename it; either is fine. Move it somewhere easy to find (Desktop or Documents).

This page lives at docs/setup-guide.html inside that folder — you can open it in a browser anytime; it does not need Node or any install step.

Open in Cursor

Use File → Open Folder (or Open…) and choose the unzipped project — the folder whose top level includes package.json.

Install dependencies

Ask Cursor to install dependencies. Approve the terminal when it runs the install step.

Node.js must be installed (current LTS is fine). If install fails on a private Paytm package, open paytm-common-storybook/README.md in this repo and follow registry notes there.

Run Storybook

Ask Cursor to start Storybook. When it is running, open the local address it prints — usually port 6010. That is the main Storybook with PODS stories.

Quick link (if Storybook is already running): http://localhost:6010

Optional: the older library-only Storybook often uses port 6006 — ask Cursor to run the paytm Storybook script from this project if you need that.

Try a demo prompt

With the repo open in Cursor, paste one of the blocks below (all use the same file: prompts/hi-pods.md). Fill in brackets; MODE tells the assistant which workflow to run.

Build UI from Figma

Follow prompts/hi-pods.md (Hi PODS).

MODE: C
FIGMA_URL: [paste Figma link with node-id]
COMPONENT_NAME: [PascalCase name]
SCOPE: component
PIXEL_FIDELITY: best-effort

Layout from a screenshot

Follow prompts/hi-pods.md (Hi PODS).

MODE: A
SOURCE: screenshot
[Attach a screenshot in the chat. Optional: describe scope in SCOPE / NOTES.]
