## How to use Typography ?
You can either refer the typography from the canvas tab and create your own css / s(a|c)ss files
or you can use the exported `_typography.scss` file from `paytm_common_ui` with the below approach

### NPM
You can import the `_typography.scss` file from `paytm_common_ui` to any of your `scss` file like below
```css
@import "~@paytm-h5-common/paytm_common_ui/styles/typography";
```
And then you can use all the variables defined in `_typography.scss` in your app

### Variables defined in `_typography.scss`

`typography-groupName-typeName-property`
