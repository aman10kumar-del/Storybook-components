## How to use Number System?

There are multiple ways for you to use PODS number tokens:

### 1. SCSS Variables

You can use the exported `_number.scss` file from `paytm_common_ui` with the below approach:

#### NPM

Import the `_number.scss` file from `paytm_common_ui` to any of your `scss` file:
```scss
@import "~@paytm-h5-common/paytm_common_ui/styles/number";
```

### Available Number Tokens

#### Unit Tokens
Basic number units that form the foundation of our number system:
```scss
$unit-0: 0px
$unit-1: 2px
$unit-2: 4px
$unit-3: 6px
$unit-4: 8px
$unit-5: 12px
$unit-6: 16px
$unit-7: 20px
$unit-8: 24px
$unit-9: 32px
$unit-10: 36px
$unit-11: 40px
$unit-12: 48px
$unit-13: 56px
$unit-14: 64px
```

#### Margin Tokens

Horizontal Margins:
```scss
$margin-horizontal-xs: 0px
$margin-horizontal-s: 8px
$margin-horizontal-m: 12px
$margin-horizontal-l: 16px
```

Vertical Margins:
```scss
$margin-vertical-xs: 0px
$margin-vertical-s: 6px
$margin-vertical-m: 8px
$margin-vertical-l: 12px
```

#### Padding Tokens

Horizontal Padding:
```scss
$padding-horizontal-xs: 0px
$padding-horizontal-s: 2px
$padding-horizontal-m: 4px
$padding-horizontal-l: 6px
$padding-horizontal-xl: 8px
$padding-horizontal-2xl: 12px
$padding-horizontal-3xl: 16px
```

Vertical Padding:
```scss
$padding-vertical-xs: 0px
$padding-vertical-s: 2px
$padding-vertical-m: 4px
$padding-vertical-l: 6px
$padding-vertical-xl: 8px
$padding-vertical-2xl: 12px
$padding-vertical-3xl: 16px
```

#### Gap Tokens
For grid and flex layouts:
```scss
$gap-xs: 0px
$gap-s: 2px
$gap-m: 4px
$gap-l: 6px
$gap-xl: 8px
$gap-2xl: 12px
$gap-3xl: 16px
$gap-4xl: 24px
```

#### Border Radius Tokens
For component corners:
```scss
$radius-xs: 0px
$radius-s: 4px
$radius-m: 8px
$radius-l: 12px
$radius-xl: 16px
$radius-2xl: 20px
$radius-3xl: 24px
$radius-max: 64px
```

### Usage Examples

```scss
.your-component {
  // Using unit tokens
  padding: $unit-4;
  margin: $unit-6;

  // Using semantic tokens
  margin: $margin-horizontal-m;
  padding: $padding-vertical-l $padding-horizontal-xl;
  gap: $gap-2xl;
  border-radius: $radius-m;
}
```
