## How to use Colors ?
There are multiples ways for you to use PODS colors 

### 1. CSS Variables (Recommended approach. Comes with auto-theming)

#### a. If you are using any of the PODS components

Color variables will be automatically added to the `:root` of your document. 

#### b. If you are not using any PODS components

If you want to just import these color tokens without using any of the PODS components, then you can import the tokens alone
```css
import "@paytm-h5-common/paytm_common_ui/styles/variables.css"
```

These variables will automatically switch its valuebased on the current theme that you are using

### 2. SCSS Variables
You can use the exported `_colors.scss` file from `paytm_common_ui` with the below approach. Please note that these variables are just
static values and you will need to manage theming support on your own if you use this.

#### NPM

You can import the `_colors.scss` file from `paytm_common_ui` to any of your `scss` file like below
```css
@import "~@paytm-h5-common/paytm_common_ui/styles/colors";
```
And then you can use all the variables defined in `_colors.scss` in your app
