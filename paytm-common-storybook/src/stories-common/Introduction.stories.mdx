# PODS - V3
---
This includes all the common components developed by the core team

## How to contribute ?
- Create JIRA for the component that you want to add / modify in H5 board
- Clone the repo https://bitbucket.org/paytmteam/paytm-common-ui/src/master/
- Checkout new branch from *master*, use JIRA# as branch name
- npm i
- Add / Modify the component, storybook & UT
- npm run storybook - for testing
- Raise PR to master
- Add prasad.nayak@paytm.com, kartik.kaushal@paytm.com as reviewers

**How to install?**

Add the below to .npmrc file
```bash
@paytm-h5-common:registry=https://nexusartifactory.paytm.com/repository/h5-npm-releases/
```

and then in the terminal, 

```bash
npm i @paytm-h5-common/paytm_common_ui@version
```

**Latest version**

3.0.3 (Released Version)

**How to import any component?**
```js
import { Button } from '@paytm-h5-common/paytm_common_ui';
```

## Theming 
PODS components follow browsers builtin `prefers-color-scheme` attribute to render components in either dark or light themes.
You can visualize different themes of a component by toggling this settings either via browser developer tools 
or by using the plugin from storybook tool bar. (See an icon in the shape of @)
